# 🎮 宝可梦 红/蓝/黄 小白完整指南（Windows）

> 让 KiraAI 的"游戏 Agent"真正玩宝可梦（第一世代 红/蓝/黄）。
> 路线：**PyBoy 模拟器（进程内）直接读游戏内存** → Jev 每回合决策 → 代码按键。
> 零截图、零 VLM、快且省 token。预计 20-40 分钟。

---

## 📦 你最终会得到什么

```
KiraAI（已运行，含游戏 Agent 插件）
   │ 直接进程内调用
PyBoy（Python 游戏模拟器，读 GB 内存/发按键）
   │
   ▼ 每回合：读 RAM → 压缩成状态 → Jev 决策 → 按键
游戏 Agent（pokemon_pyboy 适配器）
```

**重要认知**：Agent **不截屏**——它直接读 Game Boy 的内存（位置、队伍、对话、NPC、碰撞），这比任何"看屏幕"都快且准。所以需要一份**宝可梦红/蓝的 ROM**（你自己合法拥有的），以及装 PyBoy。

---

## 🪜 第一步：准备 ROM（宝可梦红/蓝/黄）

1. **合法来源**：如果你有实体卡带，可以用设备 dump 出 ROM（.gb 文件）。没有的话，互联网上有各版本 ROM（**请确认你所在地区/用途的合法性**，本指南不提供下载链接）。
2. **文件名**：建议命名简单，如 `D:\roms\pokemon-red.gb`（别放中文路径）。
3. **版本兼容性**：红/蓝/黄（第一世代，Game Boy）都行。`jev-plays-pokemon` 官方验证的是 **Pokemon Red (USA)**（SHA-1 `ea9bcae617fdf159b045185467ae58b2e4a48b9a`）。用这个版本最稳。

---

## 🪜 第二步：装 Python + PyBoy（Windows）

1. **装 Python 3.10+**：去 `https://www.python.org/downloads/` 下载 Windows 安装包。
   - 安装时**务必勾选** "Add python.exe to PATH"（加到环境变量）。
2. **验证 Python**：打开 PowerShell / CMD，输入：
   ```powershell
   python --version
   ```
   看到 `Python 3.x.x` 即成功。
3. **装 PyBoy**：
   ```powershell
   pip install pyboy
   ```
   看到 `Successfully installed pyboy` 即成功。
   - 如果 pip 慢/失败，用清华镜像：
   ```powershell
   pip install pyboy -i https://pypi.tuna.tsinghua.edu.cn/simple
   ```
4. **验证 PyBoy**：
   ```powershell
   python -c "import pyboy; print('pyboy ok')"
   ```
   输出 `pyboy ok` 即成功。

---

## 🪜 第三步：装 KiraAI 游戏 Agent 插件

1. **拿到插件**：`plugin/` 目录（本项目的 `kira-game-agent`）。
2. **放进 KiraAI**：
   - 找到 KiraAI 的 `data/plugins/`（比如 `D:\KiraAI\data\plugins\`）。
   - 把 `plugin/` 整个复制过去，改名 `kira-game-agent`。
   - 确认：`D:\KiraAI\data\plugins\kira-game-agent\manifest.json` 存在。
3. **装依赖**（KiraAI 的 Python 环境）：
   ```powershell
   pip install requests pyboy
   ```
4. **策略后端**：插件启动后会自动在后台把 laya 装好配好（推荐，免 key）。
   - 等 WebUI「游戏 Agent」配置页显示 **Laya 已就绪** 即可；切后端为 laya。
   - 国内慢/失败可手动 `python scripts\install_laya.py --mirror https://hf-mirror.com`。
   - 想用 Jev：跳过，直接在 WebUI 填 API key（见《先决条件》）。
5. **重启 KiraAI**，日志应出现：
   ```
   [plugin] [kira_game_agent] ready
   Registered 10 tools from kira-game-agent: [...]
   ```

---

## 🪜 第四步：配置 Agent（WebUI 侧边栏）

1. **打开 KiraAI WebUI**：`http://127.0.0.1:5267`。
2. **侧边栏 → 游戏 Agent** → 配置页。
3. **决策后端**：**默认已是 laya**（本地，零成本，自动安装配置，无需 key）。想用 Jev（云端）则在 WebUI「决策引擎 → 决策后端」切到 `jev` 并填 API key（见《先决条件》）。
4. **必填配置**：
   | 配置项 | 填什么 |
   |---|---|
   | TypeSafe API Key（仅当切到 Jev） | `https://console.typesafe.ai` 生成，粘贴（或设环境变量 `TYPESAFE_API_KEY`） |
   | 决策后端 | 默认 `laya`（推荐）；可切 `jev` |
   | 游戏适配器 | 选 `pokemon_pyboy` |
   | 启用的游戏 | 勾选"宝可梦 PyBoy" |
   | PyBoy ROM 路径 | `D:\roms\pokemon-red.gb`（你的 ROM 实际路径） |
   | 决策频率 | 回合制游戏建议 `1.0` Hz（每秒 1 次决策，省 token） |
5. **保存**（热生效）。
6. **验证**：配置页"状态"面板 → 点"立即重连桥" → 桥连接显示"已连接"（前提：ROM 路径正确，Agent 会启动 PyBoy 并载入 ROM）。

## 🪜 第五步：开玩（完整流程）

### 开始

**群里 @ 机器人**：
```
@bot 帮我玩宝可梦，目标是打败第一个道馆
```
Agent 的 LLM → 调用 `game_play(game="pokemon_pyboy", goal="beat the first gym")` → 启动 PyBoy → 开始自动玩。

**它会自己**：
- 走地图、对话、推进剧情（从家里出发 → 找博士 → 拿初始宝可梦 → 出镇）
- 遇敌/战斗时自动决策（打/跑/换/用药）
- 卡住时自动调整

### 互动

```
你：现在怎么样了？
→ game_state()：位置、队伍、进度摘要
你：用皮卡丘！
→ game_set_goal("use Pikachu as the lead") → 下一回合生效
你：别打那只野怪，跑！
→ game_command("cancel") 或 game_set_goal("flee from wild battles")
你：暂停
→ game_pause() / 恢复 game_resume()
```

### 自己玩 vs Agent 玩

PyBoy 有窗口模式。想让 Agent 用**可见窗口**玩（你能看着它），把适配器 `headless=False`（改 `pokemon_pyboy.py` 的默认参数）。想让它在后台快跑，保持 `headless=True`。

## 🪜 第六步：验证它真的在读内存

打一会之后，群里问：
```
@bot 我队伍里现在都有谁？
```
→ Agent 调 `game_pkm_team()`：返回队伍（species/等级/HP）——**这些是从游戏内存读出来的，不是猜的**。

```
@bot 用一下背包里的药
```
→ `game_pkm_use_item("Potion")`。

## 🛠️ 常见问题（FAQ）

| 问题 | 解决 |
|---|---|
| 桥连不上 / "游戏桥连接失败" | ① ROM 路径对吗？文件存在吗？② PyBoy 装了吗？③ 配置页"状态"看报错 |
| 启动报 `PyBoy` 相关错误 | `pip install pyboy` 重装；确认 Python 版本 ≥3.10 |
| Agent 原地不动 / 一直 wait | ① Jev key 配了吗？② 决策频率是不是太低（0.2Hz 会显得"不动"）③ 看日志（`game_logs`）里 Jev 有没有在返回决策 |
| 对话框卡住 | 游戏对话需要按 A 推进，Agent 的确认逻辑应该会自动处理；若卡住，`game_command("confirm")` 手动推 |
| 想重开 | `game_stop()` → 删存档（或换 ROM 副本）→ `game_play` 重来 |
| 卡在标题画面 | PyBoy 冷启动在标题画面，Agent 需要按 START 进菜单。手动 `game_command("menu")` 帮它进，或等它自己探索 |
| 省 token | 决策频率调低（0.5-1Hz）；对话轮次少主动问它（搭车注入只在用户发消息时发生） |

## 📁 插件文件速查（宝可梦相关）

```
plugin/
  main.py                       # 工具 game_play/game_state/game_command/game_pkm_* + 搭车注入
  bridge/adapters/pokemon_pyboy.py  # PyBoy 适配器：读 WRAM 位置/金钱/徽章/队伍 + 按键
  jev/                          # Jev 客户端/门控/记忆/state 构造
  pages/web/index.html          # WebUI 配置页（勾选 pokemon_pyboy + ROM 路径）
```

> 适配器当前实现：读位置/朝向/金钱/徽章/队伍（`W_X_COORD`/`W_PARTY_*` 等 WRAM 地址）。完整版可参照 `jev-plays-pokemon`（对话 tilemap 解码、NPC 对象内存、碰撞图）扩展——加进 `get_state()` 即可，引擎不用改。

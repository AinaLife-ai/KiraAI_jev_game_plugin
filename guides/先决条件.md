# 🔑 先决条件：KiraAI + TypeSafe API Key（两份指南共用）

> 无论玩 YGO 还是宝可梦，都需要先完成这两步。

---

## 一、确认 KiraAI 在跑，找到它的 data 目录

1. **KiraAI 是什么**：你已经在用的 AI 机器人框架（QQ/Telegram/微信等）。本插件是它的一个"插件"。
2. **找到 data 目录**：
   - 常见位置：KiraAI 安装目录下的 `data\`（如 `D:\KiraAI\data\`）。
   - 里面有 `plugins\`、`config\`、`memory\` 等文件夹 = 对了。
3. **确认版本**：KiraAI ≥ v2.33.1（本插件要求）。在 KiraAI 的启动日志或 WebUI"关于"里看版本号。

---

## 二、决策后端：默认 laya（本地，零成本），Jev 可选

本插件**默认用本地 laya**（开箱即用、零成本、中文友好），保留完整 Jev 支持（云 API，需 key），用户可随时切换。

| 后端 | 成本 | key | 语言 | 默认 |
|---|---|---|---|---|
| **Laya**（本地开源） | **$0** | **不需要** | **中文友好** | ✅ **默认** |
| **Jev**（TypeSafe 云） | $0.042/Mtok | 需要 | 中文精度低 | 可选 |

### 路线 A：用本地 laya（**默认**，零成本，免 key，自动安装配置）
1. **装好插件即可**——**默认决策后端就是 laya**，插件启动后**自动在后台**：`pip install laya` + 下载模型（默认 multilingual 支持中文），全程不打扰你。KiraAI WebUI「游戏 Agent」配置页会显示安装进度。
2. 联网正常的话，等配置页显示 **"Laya 已就绪"** 就能用，**无需任何配置**。
3. 国内网络下载慢/失败：手动跑一次镜像下载（可选）：
   ```bat
   python scripts\install_laya.py --mirror https://hf-mirror.com
   ```
4. **不用填任何 API key**。验证：`python scripts\install_laya.py --check` 输出 `OK`。
   - 想关掉自动安装：取消勾选「Laya 本地后端 → 会自动安装」。

### 路线 B：切换用 Jev（TypeSafe 云，可选，需 key）

1. **注册**：浏览器打开 `https://console.typesafe.ai`（可能需要先到 `https://typesafe.ai` 加入 waitlist / 注册）。
2. **进控制台**：登录后进 Dashboard / Console。
3. **找 Keys**：Settings → Keys（或 API Keys）→ **Create / Generate** 一个新 key。
4. **复制**：形如 `tsk_xxxxx...` 的一串字符，**只显示一次，先复制到记事本**。
5. **两种填法**（任选）：
   - **方式 A（推荐，图形化）**：KiraAI WebUI → 侧边栏"游戏 Agent" → 配置页 → "决策引擎" → API Key 粘贴 → 保存。
   - **方式 B（环境变量）**：给 KiraAI 的启动环境加 `TYPESAFE_API_KEY=tsk_xxxxx`（Windows 系统环境变量：设置 → 系统 → 高级系统设置 → 环境变量 → 新建）。
6. **验证 key 有效**：PowerShell 里执行：
   ```powershell
   curl -X POST https://api.typesafe.ai/v1/systemone -H "Authorization: Bearer tsk_xxxxx" -H "Content-Type: application/json" -d "{\"state\":\"hello\",\"model\":\"jev-latest\",\"questions\":{\"ok\":{\"type\":\"noul\",\"instructions\":\"Is this a greeting?\"}}}"
   ```
   返回 JSON 带 `"answers":{"ok":{"noul":...}}` = key 有效。

---

## 三、验证插件装好

装完插件重启 KiraAI 后，日志出现：
```
[plugin] [kira_game_agent] ready
Registered 10 tools from kira-game-agent: [...]
```
或 WebUI 侧边栏出现"游戏 Agent"图标 = 装好了。

---

## 四、成本速览（心里有数）

- Jev：输入 $42/10亿 token（≈$0.00004/千 token），**输出免费**。
- 宝可梦：约 600-900 token/回合 → 玩一小时（假设 1000 回合）≈ **$0.04**。
- YGO：每回合决策更小（手牌数+场况+合法动作）→ 一局 ≈ **$0.01 以内**。
- 对比：LLM 截图方案每帧一张图几美分——Jev 方案便宜 2-4 个数量级。
